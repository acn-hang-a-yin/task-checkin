# docs/ 目录说明

**本目录的文档已经合并到根目录，这里只留一个指路文件**（原来 `docs/README.md` 和 `docs/code-docs.md` 写的是初版「两张表 + `js/ui.js` 单页面」的内容，早已和代码不一致）。

请直接看：

| 想看什么 | 去哪看 |

| 项目全貌、数据库表结构、建表 SQL | 根目录 **`task-checkin-system.md`** 第 0 ~ 4 章 |
| 家长端 / 孩子端每个页签、每个按钮 | 同上 第 5 ~ 6 章 |

样式与兼容性（这两条仍然有效，保留在这里）：

- 主题色：主色 `#4a6cf7`、成功色 `#2ecc71`、错误色 `#e74c3c`、警告色 `#f39c12`（定义在 `css/app.css` 的 CSS 变量里）。
- 兼容性：现代浏览器（Chrome / Edge / Firefox / Safari，含手机端），使用原生 ES Module，无需打包和 polyfill。
