1. 30 秒看懂

这是一个给一个家庭用的「任务打卡 + 星星奖励」小系统：家长建任务、孩子打卡；打卡得星星，星星换奖励。

你是谁登录后进哪个页面你能做什么
👨‍👩‍👧 家长 admin.html（家长端） 建 / 改 / 暂停 / 结束 / 删除任务；看孩子的打卡记录和完成率；导出 CSV；手动加星、扣星；审核兑换；发留言
🧒 孩子 child.html（孩子端） 看今天要做什么 → 打卡（勾选 / 拍照 / 说一句）→ 得星星；看自己的日历、连续天数、勋章；用星星申请兑换；看家长留言
本页是一份独立说明文件（guide.html），系统页面上没有放它的入口： 把文件发给家人、收藏成书签或打印出来都行，随时能看，也不需要登录。
打开系统：浏览器进入 index.html（会自动分流）或 login.html（登录页）。 角色不对会被自动送回自己的页面：孩子进不了家长端，家长也进不了孩子端。

2. 每天怎么用

家长（第一次，约 5 分钟）

  1. 在 Supabase 控制台建好孩子账号（Authentication → Users → Add user，记得勾 Auto Confirm User）。
  2. 登进家长端 → 「📋 任务」→「+ 新建任务」，把任务名、周期（每天 / 每周几）、截止时间、打卡形式、几颗星填好。
  3. 「🎁 奖励」页先建几个奖励，标上需要几颗星（例如「看动画 30 分钟 = 10 ⭐」）。
  4. 「💬 消息」页发一句留言，孩子打开页面就能看到红点提醒。
  5. 之后每天看一眼「📊 记录」页：谁打卡了、哪天漏了、完成率多少。

孩子（每天）

  1. 登录后默认在「✅ 今日」，卡片上写着今天要做的任务。
  2. 做完一个就点它 → 拍照 / 写一句话 → 「提交打卡」，会提示「打卡成功！获得 N 颗星星 ⭐」。
  3. 「📅 记录」看自己的日历和连续天数；「🎁 奖励」看勋章墙和星星，够星就点「兑换」申请奖励。
两个贴心小设计：从别的 App 切回来时页面自动刷新成最新数据；5 分钟没有任何操作会自动退出登录（防止平板一直亮着没人管）。
想改名字或换头像：点右上角自己的昵称，弹窗顶部会先显示你当前的昵称和头像。

3. ★ 每个数字是怎么算出来的

先记住三条规则，后面所有数字都靠它们：

  1. 「这天打卡了」＝ 打卡表里有一条记录（同一个任务、同一天只留一条；取消或纠正都是直接删记录）。
  2. 「这天该打卡」＝ 任务处于进行中，并且周期包含这一天： 每天的任务天天算；每周的任务只算勾选的那几天（1 = 周一 … 7 = 周日）； 任务「已结束」一律不算，「已暂停」从暂停那天起不再算。
  3. 日期按手机 / 电脑的本地时间算，所以不会出现「差一天」。

① 孩子端「今日」右上角：已完成 x / y

显示怎么算
y今天该打卡的任务个数（进行中 + 周期包含今天）
x这些任务里，今天已经打过卡的个数

例：今天该做 3 个任务，打卡了 2 个 → 右上角显示「已完成 2/3」；全做完会变成绿色的「已完成 3/3」。

② 连续打卡 N 天（孩子端「记录」「奖励」，家长端「记录」顶部）

连续天数 = 从今天往前数，一天接一天有打卡记录的天数 · 今天已经打卡 → 从今天开始数 · 今天还没打卡 → 从昨天开始数（早上不会显示 0） · 哪天没有打卡记录 → 立刻停

它不管任务周期：只要当天完成过任意一个任务，这一天就算「打卡日」。断一天就归零。

③ 完成率（家长端「📊 记录」页底部）

完成率 = round( 实际打卡天数 ÷ 该打卡天数 × 100 ) 实际打卡天数：这个任务的打卡日期，同一天多条只算 1 天 ← 单位是「天」 该打卡天数 ：从任务创建那天起，按周期逐天数出来 ← 只看任务表

「该打卡天数」数到哪一天，看任务现在的状态：

任务状态数到哪天为止页面上显示
进行中今天NN% + 3/7 天
已暂停暂停那天（暂停之后不再加天数）NN% + 灰标签「已暂停（算到 2026-10-10）」
已结束最后一次打卡那天NN% + 标签「已结束」
已结束、从未打卡——百分比显示 —，副文字「结束前没有打卡记录」

举个例子（任务：每周一 / 三 / 五，10-01 创建，只在 10-02、10-05 打了卡）：

  • 进行中：该打卡日 = 10-02、10-05、10-07、10-09、10-12、10-14、10-16 → 7 天，完成 2 天 → 29%。
  • 如果它 10-10 被暂停：分母只剩 4 天 → 50%（暂停后的日子不再让人「欠账」）。
  • 如果它已结束、最后一次打卡是 10-12：分母 5 天 → 60%。
注意：系统里没有记录「暂停历史」。所以暂停之后又去编辑这个任务，或者把它恢复成进行中， 暂停期间的那几天会重新算回分母，百分比会掉下来 —— 这是目前数据结构的限制（要精确得再加一张表，暂时不做）。

④ 日历上的点（家长端「📊 记录」）

每天的颜色只看两件事：当天完成了几条 vs 当天有几个「进行中」的任务该打卡。

颜色什么时候出现
没有点这天一条打卡都没有
黄点完成了，但没做完 —— 完成条数 < 当天该打卡的任务个数
绿点全部完成（完成条数 ≥ 当天该打卡的任务个数）

鼠标停在格子上会显示「日期 完成 n 次」；点某一天，下面就会列出那天的打卡明细（照片、文字、星星）——明细里可以删除记录，删掉后星星会自动扣回。

因为它比的是任务条数而不是百分比，所以事后新增 / 删除 / 暂停任务，会让过去某一天的颜色跟着变。 例：那天完成了 1 个任务、当时只有 1 个进行中任务 → 是绿点；后来又建了 2 个进行中的任务 → 这天就变黄点了。 这是「用现在的任务清单回看历史」的做法，心里有数就行。

孩子端的日历不一样

孩子端只有绿点 / 没有点两种：这一天至少有 1 条打卡就亮绿点，不区分完成了几个任务。点日期同样能看当天照片和文字。

⑤ 家长端「📊 记录」顶部那 4 个数字

显示怎么算
连续打卡（天）见上面的 ②（断一天就归零）
累计打卡（天）有打卡的日子去重后一共几天
累计完成任务（次）打卡记录的条数（一天做了 3 个任务 = 3 次）
累计获得星星 ⭐这些打卡记录各自得了多少星，加起来（不扣家长扣星和兑换扣星）

⑥ 星星与勋章

星星余额 = 星星流水里每一笔「+n / −n」全部相加

星星什么时候变（每一笔都会留下流水，所以余额永远对得上账）：

什么时候星星变化
第一次完成某个任务的打卡+ 该任务的星星数（同一天重复提交不会重复给）
家长手动加星 / 扣星+n / −n（原因会写进流水）
家长删除一条打卡记录− 那条记录给的星星（原因「撤销打卡：任务名」）
家长同意兑换− 该奖励需要的星星（原因「兑换：奖励名」）

勋章墙（孩子端「🎁 奖励」）：用②的连续天数和 7 / 21 / 30 比，达到就点亮 🌟 / 🏅 / 🏆，没点亮会写「还差 N 天」。它是现场算的，删掉打卡勋章会立刻灭掉。

⑦ 消息红点、兑换状态

  • 红点：家长发过留言、孩子还没打开「消息」页 → 页签上的小圆点亮起。孩子打开这一页，看完全部留言后自动标记已读，红点消失（页面每 60 秒自动查一次有没有新留言）。
  • 兑换状态：提交申请后是「等待家长审核」；家长同意 → 「已通过 🎉」并扣星；家长驳回 → 「被驳回」，星星不动。同一个奖励有「待审核」时不能再申请。
  • 家长端「待审核 N」 = 所有还没审核的兑换申请条数。

4. 数据存在哪张表（速查）

表存什么哪些显示用它
tasks 任务：名称、周期（每天 / 每周几）、截止时间、打卡形式、几颗星、状态（进行中 / 暂停 / 结束）、创建时间 任务卡片、孩子端今日列表、日历的「该打卡」、完成率的分母
task_checkins 打卡记录：哪个任务、哪个孩子、哪一天、是否完成、备注、照片地址、得了多少星 日历的点、连续天数、完成率分子、4 个概览数字、CSV
star_records 星星流水：+n / −n、原因、类型（打卡自动 / 家长加 / 扣 / 兑换）、时间 星星余额、星星流水列表
rewards 奖励池：名称、说明、需要几颗星、图标、是否上架 奖励商店、家长端奖励池
reward_redemptions 兑换申请：谁、兑换什么、花几颗星、状态（待审核 / 已通过 / 已驳回）、审核备注 「我的兑换申请」、家长端审核卡
messages 家长留言：谁发给谁、内容、是否已读、时间 消息列表、红点、家长端留言历史
members 成员资料：昵称、头像 顶栏昵称头像、家长端孩子下拉框
📷 打卡照片存在 Supabase 的 Storage 桶 checkin-media 里，数据库只存一个链接

统计数字（连续天数、完成率、日历颜色、勋章、余额）都是打开页面时现算的，数据库里没有存这些统计结果，所以改一条打卡记录，所有数字会立刻跟着变。

5. 常见问题

问题答案
孩子看不到某个任务？① 任务不是「进行中」；② 是「每周」任务但一天都没勾；③ 今天不是勾选的那几天
一天能重复打卡吗？同一个任务一天只有一条记录。再点「我要打卡 / 重新记录」是覆盖当天那条，不会重复给星星
孩子打错了怎么改？孩子可以自己重新记录；家长可以到「📊 记录」点那一天 → 「删除」，星星会自动扣回
星星数好像不对？看「🎁 奖励」页的星星流水，每一笔都写了原因；余额就是这些数字相加
完成率和自己算的不一样？分母是「按当前周期从创建日回算到今天」，暂停 / 结束 / 改周期都会影响（见 ③）
过去的日历颜色变了？正常：颜色比的是「当天完成条数 vs 现在进行中的任务数」（见 ④）
想停掉一个任务但保留历史用「暂停」或「结束」，别删：删任务会连同它的打卡记录一起删掉
忘记密码 / 想加第二个孩子去 Supabase 控制台：Users 里 Reset Password，或 Add user 再建一个（孩子账号不用填角色）
怎么改自己的昵称 / 头像？点右上角自己的昵称（头像旁边那个）→ 弹窗顶部会显示你现在用的昵称和头像，选好新头像、改好名字后点「保存」；直接关掉不会改动
为什么 5 分钟就退出了？这是防遗忘的自动登出，没有任何鼠标 / 键盘 / 触屏动作就会计时（见第 2 节）
用手机能用吗？可以，页面是响应式的，手机上点「我要打卡」可以直接调相机拍照

6. 给维护者（自己改代码时看）

  • 想改数字口径：统计逻辑都集中在 js/stats.js（纯函数）：连续天数 getOverallStreak()、完成率 getRateRange() + getCompletionRate()、日历 buildMonthMatrix() + isTaskScheduledOn()、勋章 getBadgeStates()。改完可以直接用 node 跑一遍验证。
  • 想加字段：数据库加列 → 对应 js/xxx-api.js 读写 → admin-ui.js / child-ui.js 渲染 → 更新 task-checkin-system.md 和本页。
  • 新增页面：顶部时钟用 startClock()，无操作登出用 startIdleLogout()，提示 / 弹窗用 ui-common.js，入口守卫用 requireAuth(['admin'|'user'])。
  • 数据库表结构 / 建表 SQL：见 task-checkin-system.md 第 4 章（7 张表 + Storage 桶，可重复执行）。
  • 改完记得同步：更新 MD 的「更新日志」和相关章节，需要时再改这一页。
  • 本地打开请用 http://（VS Code Live Server 或 python -m http.server），直接双击 html 会因为浏览器限制 ES Module 而白屏。
